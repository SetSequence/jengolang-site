restrictions:
  - text: "〜ないうちに frames the action as seizing the window before a change occurs, so the main clause is usually something you do on purpose to beat that change. It isn't a neutral 'before': for plain sequencing of two events, 〜前{まえ}に is the unmarked choice."
contrasts:
  - slug: "mae-ni"
    label: "前に"
    distinction: "前{まえ}に is the neutral 'before ~ing' that just orders two events (寝{ね}る前{まえ}に歯{は}を磨{みが}く). 〜ないうちに adds urgency — act now, before an undesirable change happens (暗{くら}くならないうちに = 'before it gets dark on us')."
  - slug: "uchi-ni"
    label: "うちに"
    distinction: "Affirmative 〜うちに means 'while the favourable state lasts' (元気{げんき}なうちに = 'while you're still healthy'). The negative 〜ないうちに means 'before the state changes for the worse' — the same window seen from the opposite side."
