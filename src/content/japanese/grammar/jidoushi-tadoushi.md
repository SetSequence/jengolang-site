  - "intransitive vs transitive verbs — many Japanese verbs come in pairs: one where the thing changes by itself (intransitive, 自動詞{じどうし}) and one where someone does it to an object (transitive, 他動詞{たどうし})"
keySentence:
  jp: "ドアが開{あ}く。ドアを開{あ}ける。"
  en: "The door opens. / I open the door."
formation:
  - attaches_to: "Verb pairs"
    form: "自動詞{じどうし}: 〜が + V (it happens) / 他動詞{たどうし}: 〜を + V (someone does it)"
    example: "開{あ}く・開{あ}ける / 閉{し}まる・閉{し}める / 始{はじ}まる・始{はじ}める"
restrictions:
  - text: "The intransitive takes が (the subject undergoes the change); the transitive takes を (the object is acted on). Marking an intransitive object with を is a classic error: ×ドアを開{あ}く — say ドアが開{あ}く or ドアを開{あ}ける."
contrasts:
  - slug: "te-aru"
    label: "〜てある"
    distinction: "Resulting states split by transitivity: 窓{まど}が開{あ}いている uses the intransitive (a natural state — the window is open), while 窓{まど}が開{あ}けてある uses the transitive (someone deliberately opened it and left it that way)."
examples:
  - jp: "電気{でんき}が消{き}えた。電気{でんき}を消{け}した。"
    en: "The light went out. / I turned off the light."
  - jp: "お湯{ゆ}が沸{わ}く。お湯{ゆ}を沸{わ}かす。"
    en: "The water boils. / I boil the water."
  - jp: "授業{じゅぎょう}が始{はじ}まる。授業{じゅぎょう}を始{はじ}める。"
    en: "Class begins. / I begin class."
notes:
  - text: "There's no single rule for which ending is which, but common patterns recur: 〜まる／〜める, 〜く／〜ける, 〜る／〜す. The pairs are best learned together."
