restrictions:
  - text: "Here 何 is an indefinite 'some (large) number,' not a question. In an affirmative sentence 何+counter+も = 'as many as / many'; the bigger scale uses 何十{なんじゅう}も・何百{なんびゃく}も ('dozens / hundreds of')."
contrasts:
  - slug: "mo-2"
    label: "も (even)"
    distinction: "Both emphasize quantity with も. 三度{さんど}も = 'as many as three times' pins a specific number; 何度{なんど}も is the indefinite version — 'an unspecified large number of times.' 何〜も is 三〜も with the number left vague."

  - jp: "その映画{えいが}は何回{なんかい}も見{み}た。"
    en: "I've seen that movie many times."
notes:
  - text: "Don't confuse with 何{なに}も + negative ('nothing': 何{なに}も食{た}べない), which uses bare 何 + も rather than 何 + counter + も."
